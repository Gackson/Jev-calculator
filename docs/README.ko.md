# jev-olympics

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [Español](README.es.md) · **한국어**

Let Jev do math, chat, and draw things—in a probabilistic way.

Jev가 확률을 바탕으로 계산하고, 대화하고, 그림을 그리는 실험입니다. [온라인 체험](https://jev-olympics.vercel.app/)

## 기능

- **Calculator:** Choice로 일의 자리부터 숫자를 선택하거나, Noul의 ‘같다 / 크다 / 작다’ 판단으로 정수를 찾습니다. 예측을 정확한 계산 결과와 비교합니다.
- **Chat:** 영어 답변을 한 글자씩 또는 한 단어씩 만듭니다. 단어 모드에는 자주 쓰는 영어 단어 249개, `. , ? !`, 줄바꿈, 종료까지 총 255개 선택지가 있습니다. 단어 사이 공백은 자동으로 추가됩니다.
- **Canvas:** 4×4~14×14 흑백 격자에 순차 스캔, 좌표 선택, 볼펜 모드로 그림을 그립니다.
- **Notes:** 모든 판단에 공통 지시나 격려를 추가합니다. 내장 지시보다 우선하지만, 출력은 해당 판단의 선택지 안에서 이루어집니다.

숫자, 글자, 단어, 그리기 판단을 클릭하면 확률, confidence(제공되는 경우), 모델, 소요 시간과 토큰 수를 볼 수 있습니다. ‘전체 입력 보기’는 기본적으로 접혀 있으며 인증 정보를 제외한 실제 JSON을 표시합니다. 예측 결과를 보정하지 않습니다. UI는 6개 언어를 지원하며, 언어를 바꿔도 모델 지시나 출력은 번역하지 않습니다. 새로고침하면 대화, 그림, Notes, 개인 키가 지워집니다.

## 공유 키와 개인 키

공개 사이트는 기본적으로 서버의 공유 키를 사용하므로 키 없이 체험할 수 있습니다. 오른쪽 위 버튼에서 개인 TypeSafe 키를 입력하면 개인 키가 우선됩니다. 지우면 공유 키로 돌아갑니다. 개인 키가 거절되어도 사이트 소유자의 할당량으로 자동 전환되지 않습니다.

[TypeSafe 콘솔](https://console.typesafe.ai/keys)에서 키를 만들 수 있습니다. 개인 키는 현재 페이지 메모리에만 보관되며 HTTPS로 백엔드에 전송됩니다. 공유 키는 브라우저로 전달되지 않습니다.

## 로컬 실행

Python 3.9 이상이 필요합니다. TypeSafe 모드에는 추가 의존성이 없습니다. 프로젝트 루트에서 실행하세요.

```bash
python3 calculator.py
```

<http://127.0.0.1:8765>를 엽니다. `--port 8766`으로 포트를 바꿀 수 있습니다. 기본 모델은 `jev-1.13.0`입니다.

루트의 `.env`에 `TYPESAFE_API_KEY`를 설정할 수 있습니다. 로컬 우선순위는 프로세스 환경 변수 → `.env` → 브라우저 개인 키입니다. 환경 키를 바꾸면 서버를 재시작하세요. 공개 사이트와 달리 로컬 환경 키가 개인 키보다 우선합니다. 실제 키를 Git에 커밋하지 마세요.

## Vercel 배포

**Production**에 `TYPESAFE_API_KEY`를 **Secret**으로 추가한 뒤 다시 배포합니다.

```bash
vercel env add TYPESAFE_API_KEY production --sensitive
vercel deploy --prod
```

키는 CLI 프롬프트로 입력하고 명령 인자나 소스에 쓰지 마세요. `VERCEL_ENV=production`일 때만 공유 키가 활성화됩니다. 미리보기 배포는 계속 개인 키를 요구합니다. 클라우드는 `.env`나 로컬 Laya 가중치를 읽지 않습니다. 변수를 제거하고 다시 배포하면 공유 사용이 비활성화됩니다.

공개 체험은 사이트 소유자의 TypeSafe 할당량을 사용하며, 소유자가 콘솔에서 관리합니다. 앱에는 여러 인스턴스에 걸친 전역 비용 한도나 요청 속도 제한이 없습니다. 동일 출처 검사만으로 스크립트의 직접 호출을 막을 수는 없습니다.

## 종료 조건과 개발

글자 모드는 연속 공백 두 개 또는 같은 글자 다섯 개가 나오면 멈춥니다. 단어 모드는 같은 단어나 기호를 다섯 번 연속 선택하면 멈춥니다. 글자 제한은 64 / 128 / 256, 단어 모드의 판단 횟수 제한은 32 / 64 / 128입니다. 제한이나 반복으로 멈춘 답변은 미완료로 표시하며 `END`를 임의로 만들지 않습니다. 그리기도 격자 경계, 반복, 단계 제한을 적용하고 중간 결과를 보존합니다.

테스트는 `tests/`에 모여 있으며 유료 API를 호출하지 않습니다.

```bash
python3 -m unittest discover -s tests -t . -v
python3 -m unittest tests.test_chat_words -v
```

프런트엔드는 `calculator_ui/`, 클라우드 진입점은 `api/`, 번역은 `docs/`에 있습니다. 선택 사항인 로컬 Laya는 API 키가 필요 없고, 실패해도 클라우드로 전환하지 않습니다. 알고리즘, Laya 설치, 전체 구조는 [영문 README](../README.md)를 참고하세요.
