# jev-olympics

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語** · [Español](README.es.md) · [한국어](README.ko.md)

Let Jev do math, chat, and draw things—in a probabilistic way.

Jev に確率で計算、会話、お絵描きをさせる実験です。[オンラインで試す](https://jev-olympics.vercel.app/)

## 機能

- **Calculator**：Choice で一の位から数字を選ぶか、Noul の「等しい／大きい／小さい」という判定で整数を探します。予測を正確な計算結果と比較できます。
- **Chat**：英語の回答を一文字ずつ、または一単語ずつ作ります。単語モードには日常的な英単語 249 個、`. , ? !`、改行、終了の計 255 選択肢があります。単語間の空白は自動挿入されます。
- **Canvas**：4×4〜14×14 の白黒グリッドに、順次走査、座標選択、ボールペンの各モードで描画します。
- **Notes**：共通の指示や励ましを各判定に追加します。組み込み指示より優先されますが、出力はその判定の選択肢に限定されます。

数字、文字、単語、描画の判定をクリックすると、確率、confidence（ある場合）、モデル、処理時間、トークン使用量を確認できます。「入力全体を表示」は既定で折りたたまれており、認証情報を除いた実際の JSON を表示します。予測結果は補正しません。UI は 6 言語に対応し、言語を変更してもモデルへの指示や回答は翻訳しません。再読み込みすると会話、描画、Notes、個人キーは消去されます。

## 共有キーと自分のキー

公開サイトはサーバー側の共有キーを使うため、キーを入力せず試せます。右上のボタンから自分の TypeSafe キーを入力すると、そのキーを優先します。削除すると共有キーに戻ります。個人キーが拒否されても、サイトの利用枠には自動で切り替えません。

キーは [TypeSafe コンソール](https://console.typesafe.ai/keys) で取得できます。個人キーは現在のページのメモリだけに保持され、HTTPS でバックエンドに送信されます。共有キーはブラウザーに送信されません。

## ローカル実行

Python 3.9 以上が必要です。TypeSafe モードに追加依存はありません。プロジェクトのルートで実行します。

```bash
python3 calculator.py
```

<http://127.0.0.1:8765> を開きます。`--port 8766` でポートを変更できます。既定モデルは `jev-1.13.0` です。

ルートの `.env` に `TYPESAFE_API_KEY` を設定することもできます。ローカルの優先順位はプロセス環境変数 → `.env` → ページの個人キーです。環境キーを変更したら再起動してください。公開サイトと異なり、ローカルでは環境キーが個人キーより優先されます。本物のキーをコミットしないでください。

## Vercel へのデプロイ

**Production** に `TYPESAFE_API_KEY` を **Secret** として追加し、再デプロイします。

```bash
vercel env add TYPESAFE_API_KEY production --sensitive
vercel deploy --prod
```

キーはプロンプトで入力し、コマンド引数やソースには記載しません。共有キーは `VERCEL_ENV=production` の場合だけ有効です。プレビューは引き続き個人キーを要求します。クラウドでは `.env` やローカルの Laya 重みを読み込みません。変数を削除して再デプロイすると共有利用を無効化できます。

公開利用はサイト所有者の TypeSafe 利用枠を消費し、所有者がコンソールで管理します。アプリにはインスタンスをまたぐ利用上限やレート制限がありません。同一オリジンの検査だけではスクリプトによる直接呼び出しを防げません。

## 停止条件と開発

文字モードは空白が 2 回連続、または同じ文字が 5 回連続すると停止します。単語モードは同じ単語や記号を 5 回連続で選ぶと停止します。文字上限は 64 / 128 / 256、単語モードの判定上限は 32 / 64 / 128 です。上限や反復による停止は未完了と表示し、`END` を捏造しません。描画にも境界、反復、ステップ数の制限があり、途中結果を保持します。

テストは `tests/` にまとめてあり、有料 API を呼び出しません。

```bash
python3 -m unittest discover -s tests -t . -v
python3 -m unittest tests.test_chat_words -v
```

フロントエンドは `calculator_ui/`、クラウドの入口は `api/`、翻訳は `docs/` にあります。任意で利用できるローカル Laya は API キー不要で、失敗時にクラウドへ切り替えません。詳細なアルゴリズム、Laya の設定、ディレクトリ構成は [英語版](../README.md) を参照してください。
